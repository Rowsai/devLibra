# devLibra

![devLibra icon](image/icon.png)

`devLibra` は、FINAL FANTASY XIV の Dalamud プラグイン開発を支援するユーティリティです。

## 主な機能

### For PvP Battle（v1.0.0.4・仕様修正版）

- 左メニュー「For PvP Battle」で有効・無効を切り替えます。初期値は無効です。
- クリスタルコンフリクト限定です。フロントライン・ライバルウィングズ・ウルヴズジェイル係船場では動作しません。
- 敵リスト1～5番ごとに、変更先のマクロを「個人用／共有・番号0～99・名前」から事前に選択します。未設定の行には適用しません。設定は自動保存します。
- 例：敵リスト1番に個人用マクロ00を割り当てると、敵1番がナイトの場合、ホットバー上のマクロ00がナイトのジョブアイコンになります。
- ゲーム標準の敵リスト順（`<e1>`～`<e5>`）から対象プレイヤーを取得し、100msごとに更新します。マクロ実行・マーカー付与は不要です。マクロのコマンド内容は問いません。
- 同じマクロを別の敵番号に設定した場合、以前の割り当てを解除します。各行に取得中の敵とジョブを表示します。
- 通常・クロスホットバーに置いた指定マクロに反映します。同じマクロを複数スロットに置いた場合はすべて反映し、`/micon` の表示にも優先します。スロット位置を変更してもマクロへの割り当てを維持します。
- マクロ本文・実行内容・保存済みアイコンは変更しません。取得できない敵、未設定のマクロ、機能無効時、クリコン外では元のアイコンになります。
- 旧仕様のマクロ実行・マーカー付与監視は削除しました。バージョンは1.0.0.4を維持しています。
- API15のReleaseビルドと割り当て・重複・解除・設定保存の自動テストを実施。実ゲームでの敵リスト取得、ホットバー描画、復元は未確認です。
- 実機確認：敵1～5に別々の個人用／共有マクロを設定してクリコンに参加 → マクロを押さずにアイコンが各ジョブになることを確認 → 通常・クロスホットバーと割り当て変更を確認 → 無効化／退出時の復元を確認してください。

### Titles Search（v1.0.0.3）

- 左メニューの「Titles Search」のボタンで有効・無効を切り替えます。初期値は無効、設定は保存されます。
- ゲームの称号一覧を開くと、上部に追従する検索バーを表示します。
- 取得済みの称号を部分一致検索します。男女両方の名称に対応し、英字の大小・全半角・ひらがな／カタカナを区別しません。
- 入力中はゲームの一覧の上に検索結果を重ねて表示します。結果をクリックすると「称号を設定しますか？対象：＊＊＊」と確認します。OKで称号を変更し、Cancelでは変更せず検索結果へ戻ります。空欄・クリアで元の一覧へ戻ります。
- 一覧を閉じた場合、無効化、ログアウト時には検索表示と入力をリセットします。元の一覧データや取得状態は変更しません。
- ホームの設定一覧にも表示します。既存のPvP制御対象4機能は変更していません。
- API15のReleaseビルドと検索ルールの自動テストを確認。実ゲームでの配置・入力・称号変更は未確認です。

### View DoT Icons

- 自分が付与したDoTのアイコンを、表示中の敵ネームプレートの上・右・左に表示します。
- アイコン内に残り秒数を重ね、複数のDoTは横並びで表示します。
- `View DoT Icons` タブの「有効」で切り替えます。初期値はOFFです。
- `/dl show dot` でもON/OFFを切り替え、設定を保存します。タブに現在の状態とコマンドの使用可否を表示します。
- 詳細と実機確認項目は [View DoT Icons](VIEW_DOT_ICONS.md) を参照してください。

### Change Party Icons

- パーティメンバーに付与されたターゲットマーカーをジョブアイコンの位置に表示します。
- マーカー変更・解除を描画時に確認し、解除時・機能無効化時・プラグインのアンロード時にジョブアイコンへ戻します。
- `/devlibra` → `Change Party Icons` タブに「有効」チェックボックスを1個追加しています。初期値は有効、設定は自動保存します。
- 攻撃1～8、足止め1～3、禁止1～2、四角・丸・バツ・三角の17種に対応します。通常パーティリストの最大8人が対象です。
- 導入方法と確認状況は [移植版の手順](CHANGE_PARTY_ICONS.md) を参照してください。

### ターゲットマーカー順で並び替え

- `/sort tm asc`: 攻撃1～8 → 足止め1～3 → 禁止1～2。
- `/sort tm desc`: 上記の逆順。
- `/sort tm original`: Change Party Icons タブで設定したオリジナル順を適用。
- `/sort default`: ゲームの `/partysort` を実行。
- オリジナル順は「オリジナルのソート順を有効化」をチェックすると設定を表示します。ドラッグで優先順位を変更し、昇順／降順を選択できます。
- 自分の先頭行と対象外メンバーの位置を維持します。コマンド実行時に1回並び替えます。
- 詳細と確認状況は [ソート機能の説明](PARTY_SORT.md) を参照してください。

### Barrier HP

- パーティリストの現在 HP 表示にバリア量を加算して表示します。
- バリア量を含む HP 数値は緑色で表示します。
- 鼓舞激励の策のバリアは、付与時に観測した回復量の 180% から算出します。
- 戦闘外では、現在 HP・最大 HP・バリア量・計算結果・計算元などを Barrier HP タブで確認できます。
- デバッグ情報は戦闘中には表示しません。

### PartySearch

- 自キャラ以外の100m以内にいる「コンテンツ参加中」アイコンのプレイヤーをソロ対象として扱います。戦闘中は無効です。
- PartySearch タブから、対象のローカル表示名・名前色・自キャラから引くターゲット線の色と太さを設定できます。

### 開発支援タブ

- PartyMember: ObjectTable 上のプレイヤー情報とステータスを確認します。
- EnemyCasting: 敵のキャスト情報を確認します。
- EnemyStatus: 敵に付与されているステータスを確認します。
- StatusSearch: ステータスを名前または ID で検索します。
- ActionSearch: アクションを名前または ID で検索します。

## 設定を開く

ゲーム内で `/devlibra` を実行するか、Dalamud のプラグイン設定画面から開きます。

## Which Activate to PVP（v1.0.0.1）

4つのチェックボックスで、Barrier HP / PartySearch / Change Party Icons / View DoT IconsのPvP参加中の使用を許可できます。初期値は全てOFFです。チェックなしの機能は各タブの通常設定がONでもPvP中は停止します。チェックありでも通常設定がOFFの機能を強制的にONにはしません。

PvP判定はDalamudのIsPvPExcludingDenを使い、ウルヴズジェイル係船場は除外します。通常設定を書き換えずに制限するため、退出後は元の設定で再開します。設定変更は自動保存し、各機能のタブにPvPによる停止状態を表示します。

- Barrier HP: HP表示を通常値・通常色に戻し、計算と表示変更を停止。
- PartySearch: 名前変更、色変更、線、近隣一覧、招待処理を停止。名前の再描画を要求。
- Change Party Icons: ジョブアイコンを復元。/sortによる並び替えも停止。
- View DoT Icons: DoTとデスデザインの表示を停止。/dl show dotで通常設定を変更してもPvP中の制限を優先。

Releaseビルド成功（既存警告5件・エラー0）。既存のソートおよびDoTロジックテスト成功。PvP入場・退出、参加中の設定変更、表示の復元はゲーム内未検証です。
